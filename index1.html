Bevezetés

A MySQL az egyik legnépszerűbb relációs adatbázis-kezelő rendszer, amelyet weboldalak és alkalmazások adatainak tárolására használnak. Az adatbázisok segítségével rendszerezett módon kezelhetjük az adatokat, valamint gyors lekérdezéseket és módosításokat végezhetünk.

Ebben az összefoglalóban bemutatjuk a legfontosabb táblakorlátozásokat és az alapvető SQL lekérdezéstípusokat gyakorlati példák segítségével.

1. Táblákban alkalmazható korlátozások

A korlátozások (constraints) biztosítják az adatok helyességét és megbízhatóságát az adatbázisban.

PRIMARY KEY

A PRIMARY KEY (elsődleges kulcs) egy olyan mező, amely minden rekordot egyedileg azonosít.

Példa:

                CREATE TABLE diakok (
                    id INT PRIMARY KEY,
                    nev VARCHAR(100),
                    eletkor INT
                );

Magyarázat:

  • Az "id" mező minden rekordnál egyedi lesz.
  • Nem tartalmazhat ismétlődő vagy NULL értéket.
  • Egy táblában csak egy PRIMARY KEY lehet.

FOREIGN KEY

A FOREIGN KEY (idegen kulcs) kapcsolatot hoz létre két tábla között.

Példa

                CREATE TABLE osztalyok (
                    osztaly_id INT PRIMARY KEY,
                    osztaly_nev VARCHAR(50)
                );

                CREATE TABLE tanulok (
                    tanulo_id INT PRIMARY KEY,
                    nev VARCHAR(100),
                    osztaly_id INT,
                    FOREIGN KEY (osztaly_id) REFERENCES osztalyok(osztaly_id)
                );

Magyarázat

  • A tanulok tábla kapcsolódik az osztalyok táblához.
  • Csak olyan osztaly_id adható meg, amely létezik az osztalyok táblában.
  • Segít megőrizni az adatok közötti kapcsolatokat.

UNIQUE

A UNIQUE korlátozás biztosítja, hogy egy mezőben ne legyen két azonos érték

.

Példa

                CREATE TABLE felhasznalok (
                    id INT PRIMARY KEY,
                    email VARCHAR(100) UNIQUE
                );

Magyarázat

  • Két felhasználónak nem lehet ugyanaz az email címe.
  • Az ismétlődő adatok elkerülésére használjuk.

NOT NULL

A NOT NULL korlátozás megakadályozza, hogy egy mező üres maradjon.

Példa

                CREATE TABLE termekek (
                    id INT PRIMARY KEY,
                    nev VARCHAR(100) NOT NULL,
                    ar INT
                );

Magyarázat

  • A nev mező kitöltése kötelező.
  • NULL érték nem adható meg.
