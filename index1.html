MySQL adatbázis-kezelés alapjai

Bevezetés

A MySQL az egyik legnépszerűbb relációs adatbázis-kezelő rendszer, amelyet weboldalak és alkalmazások adatainak tárolására használnak. Az adatbázisok segítségével rendszerezett módon kezelhetjük az adatokat, valamint gyors lekérdezéseket és módosításokat végezhetünk.

Ebben az összefoglalóban bemutatjuk a legfontosabb táblakorlátozásokat és az alapvető SQL lekérdezéstípusokat gyakorlati példák segítségével.

1. Táblákban alkalmazható korlátozások

A korlátozások (constraints) biztosítják az adatok helyességét és megbízhatóságát az adatbázisban.

PRIMARY KEY

A PRIMARY KEY (elsődleges kulcs) egy olyan mező, amely minden rekordot egyedileg azonosít.

Példa:

                CREATE TABLE diakok (
                    id INT PRIMARY KEY,
                    nev VARCHAR(100),
                    eletkor INT
                );

Magyarázat:

  • Az "id" mező minden rekordnál egyedi lesz.
  • Nem tartalmazhat ismétlődő vagy NULL értéket.
  • Egy táblában csak egy PRIMARY KEY lehet.

FOREIGN KEY

A FOREIGN KEY (idegen kulcs) kapcsolatot hoz létre két tábla között.

Példa

                CREATE TABLE osztalyok (
                    osztaly_id INT PRIMARY KEY,
                    osztaly_nev VARCHAR(50)
                );

                CREATE TABLE tanulok (
                    tanulo_id INT PRIMARY KEY,
                    nev VARCHAR(100),
                    osztaly_id INT,
                    FOREIGN KEY (osztaly_id) 
                    REFERENCES osztalyok(osztaly_id)
                );

Magyarázat

  • A tanulok tábla kapcsolódik az osztalyok táblához.
  • Csak olyan osztaly_id adható meg, amely létezik az osztalyok táblában.
  • Segít megőrizni az adatok közötti kapcsolatokat.

UNIQUE

A UNIQUE korlátozás biztosítja, hogy egy mezőben ne legyen két azonos érték

.

Példa

                CREATE TABLE felhasznalok (
                    id INT PRIMARY KEY,
                    email VARCHAR(100) UNIQUE
                );

Magyarázat

  • Két felhasználónak nem lehet ugyanaz az email címe.
  • Az ismétlődő adatok elkerülésére használjuk.

NOT NULL

A NOT NULL korlátozás megakadályozza, hogy egy mező üres maradjon.

Példa

                CREATE TABLE termekek (
                    id INT PRIMARY KEY,
                    nev VARCHAR(100) NOT NULL,
                    ar INT
                );

Magyarázat

  • A nev mező kitöltése kötelező.
  • NULL érték nem adható meg.

DEFAULT

A DEFAULT alapértelmezett értéket ad egy mezőnek.

Példa

CREATE TABLE rendelesek (
                    id INT PRIMARY KEY,
                    statusz VARCHAR(50) 
                    DEFAULT 'Feldolgozás alatt'
                );

Magyarázat

  • Ha a statusz mező nincs megadva, automatikusan a „Feldolgozás alatt” értéket kapja.

CHECK

A CHECK korlátozás feltételt ad meg az adatokra.

Példa

CREATE TABLE dolgozok (
                    id INT PRIMARY KEY,
                    nev VARCHAR(100),
                    fizetes INT CHECK (fizetes > 0)
                );

Magyarázat

  • A fizetés csak pozitív szám lehet.
  • Hibás adatbevitel esetén a rendszer hibát jelez.

2. A lekérdezések típusai

Az SQL nyelv segítségével adatokat vihetünk be, lekérdezhetünk, módosíthatunk és törölhetünk.

Adatbevitel – INSERT

Az INSERT utasítás új rekordok hozzáadására szolgál.

Példa

INSERT INTO diakok (id, nev, eletkor)
                VALUES (1, 'Kiss Péter', 18);

Magyarázat

  • Új sort adunk hozzá a diakok táblához.
  • Az értékek sorrendje megegyezik az oszlopok sorrendjével.

Adatlekérdezés – SELECT

A SELECT utasítással adatokat kérdezhetünk le.

Példa

SELECT * FROM diakok;
                Magyarázat
                A * az összes oszlopot jelenti.
                A lekérdezés minden rekordot megjelenít.
                Feltételes lekérdezés
                SELECT nev, eletkor
                FROM diakok
                WHERE eletkor >= 18;

Magyarázat

  • Csak a 18 éves vagy idősebb diákokat jeleníti meg.

Adatmódosítás – UPDATE

Az UPDATE meglévő adatok módosítására szolgál.

Példa

UPDATE diakok
                SET eletkor = 19
                WHERE id = 1;

Magyarázat

  • Az id = 1 rekord életkorát 19-re módosítjuk.
  • A WHERE feltétel nagyon fontos, különben minden rekord módosulhat.

Adattörlés – DELETE

A DELETE rekordok törlésére használható.

Példa

DELETE FROM diakok
                WHERE id = 1;

Magyarázat

  • Törli azt a rekordot, amelynek azonosítója 1.

Összegzés

A MySQL adatbázis-kezelés alapját a megfelelően kialakított táblák és az SQL lekérdezések adják. A különböző korlátozások segítenek az adatok pontosságának megőrzésében, míg az SQL utasítások lehetővé teszik az adatok kezelését.

A legfontosabb műveletek:
PRIMARY KEY egyedi azonosítás
FOREIGN KEY kapcsolatok létrehozása
UNIQUE ismétlődés tiltása
NOT NUL kötelező mező
DEFAULT alapértelmezett érték
CHECK feltételek ellenőrzése
SQL műveletek:
INSERT adatbevitel
SELECT adatlekérdezés
UPDATE adatmódosítás
DELETE adattörlés
